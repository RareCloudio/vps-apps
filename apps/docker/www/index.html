Publish an app on your domain

This page is served on the name you gave this server. Give each of your own containers a name that points to this server, and add these two labels to its service. The proxy picks them up and gets a certificate for the name.

caddy: myapp.example.com
caddy.reverse_proxy: "{{upstreams 3000}}"

Put the service on the network web so the proxy can reach it:

services:
  app:
    image: your-image
    labels:
      caddy: myapp.example.com
      caddy.reverse_proxy: "{{upstreams 3000}}"
    networks:
      - web

networks:
  web:
    external: true

Other ports

A published container port other than 80 and 443 stays closed until you open it, for example rc port open 5432/tcp.

Commands

rc status
rc logs
